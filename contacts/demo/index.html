Contacts import — desktop fallback demo

"Fill with mock data" is fully static and never touches a real file. "Import CSV" sends the file you pick to the small local server running on your own machine (started with python3 -m contacts.demo.server, see contacts/README.md) — that server runs the same tested Python parser as the rest of this library, so there's only one parser to keep correct. The file never goes further than 127.0.0.1: this Claude Code session has no access to that server or anything sent to it.
