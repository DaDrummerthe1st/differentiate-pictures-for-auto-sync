# Make git push to master and new-branch publish autonomous for bigger changes

Joakim explicitly instructed that push to `master` and publishing new branches for
coherent/bigger changes should be autonomous, not hand-over-only — the 2026-07-17
rule was scoped too narrowly ("current branch only"). Merging *into* `master` still
needs confirmation first; only the push/publish step after that confirmation changes.
Force-push and history rewrites are untouched.
