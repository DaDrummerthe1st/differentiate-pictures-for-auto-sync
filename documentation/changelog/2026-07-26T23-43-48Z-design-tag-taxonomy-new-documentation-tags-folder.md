# Design tag taxonomy: new documentation/tags folder

Designed a 12-category tag taxonomy (origin, people, quality, objects, animals,
places, privacy, relationships, activity/occasion, story/narrative,
temporal/seasonal, co-presence/group) covering Joakim's own use cases (tagging a
late pet as one searchable entity, relationship-graph search for "dad", every tag
shareable as an album with a blur-preview privacy review). Given its own
cross-cutting folder, alongside `policies/`, rather than scattered across
`photo-server/` and `upload-and-share/` docs — consolidation of those follows in
subsequent commits.
