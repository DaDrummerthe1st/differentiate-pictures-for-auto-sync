# Recover plan files from workstation repo, add plansDirectory

A separate session had symlinked Claude Code's global `~/.claude/plans/` folder into the `workstation` repo, which — since plans aren't per-project by default — pulled this project's three most recent plan files (tag taxonomy design, detector build plan, doc_metrics tooling plan) into a repo scoped to hardware/OS/network, not project work. Moved all three into `documentation/plans/` here, and set `"plansDirectory": "documentation/plans"` in `.claude/settings.json` so future plans this project generates save straight into this repo instead of the shared global folder. See the `workstation` repo's [documentation/bugs/claude-bugs/fixed/2026-08-07-dpfas-plan-files-wrongly-committed-into-workstation-repo.md](../../../../resources/workstation/documentation/bugs/claude-bugs/fixed/2026-08-07-dpfas-plan-files-wrongly-committed-into-workstation-repo.md) for the full incident writeup.
